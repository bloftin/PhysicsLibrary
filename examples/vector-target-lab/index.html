The endpoint can slide, but not leave the surface

The vector is the unknown; J is a scalar

The starting point A and duration T are fixed for each problem. The unknown is an entire path q(t) = (x(t), y(t), z(t)) on [0, T]. Its endpoint B can move anywhere on the selected target.

J[q] = ½∫0T ||q′(t)||2 dt
q(0) = A,   g(q(T)) = 0

Only the endpoint is constrained: the path need not lie on the surface, and crossing the target before T is allowed. This is not a first-impact or obstacle problem.

The interior Euler–Lagrange equation is q″ = 0, so every interior stationary path is a constant-speed straight segment. Different segments can nevertheless have different endpoint stationarity.

The interval is fixed. Changing T selects a different problem; it does not introduce a free-arrival-time boundary condition.

Why the momentum is a surface normal

An admissible endpoint displacement ηB lies in the tangent plane: ∇g(B)·ηB = 0. With the start fixed, integration by parts gives

δJ = −∫0T q″·η dt
+ p(T)·ηB,   p = q′.

Once q″ = 0, stationarity requires p·ηB = 0 for every tangent direction. Equivalently, p = λ∇g(B), or pt = 0. Parallel and antiparallel both count: the multiplier may be negative.

A zero derivative in just one chosen direction is not sufficient. The tangential residual checks the entire tangent plane, not just the rotating green arrow.

Here momentum equals velocity because this particular integrand is ½||q′||2. For a different integrand, the normality condition belongs to generalized momentum ∇q′F, not necessarily to the velocity.

J[q] ≥ ||B − A||2/(2T)
≥ dist(A, S)2/(2T)

Cauchy–Schwarz gives the first bound, with equality for a constant-speed straight segment. For the displayed exterior-start convex targets, the second bound is attained at the unique nearest point B*. Together these facts prove the global minimum, rather than merely asserting it from stationarity.

Separating an interior error from an endpoint error

The optional vertical bend uses q(t) = A + s(B − A) + h sin(πs)ez, with s = t/T. It preserves both endpoints. Its extra energy is π2h2/(4T), and it has a nonzero interior residual whenever h ≠ 0.

For the endpoint test, the full variation is η(t) = sηB. The right-hand plot separates the boundary term from the total first variation; the displayed interior contribution supplies their difference. They agree when h = 0. Neither a normal-looking endpoint nor one zero directional derivative repairs a bent path's interior Euler–Lagrange error.

The green vector is an infinitesimal allowed displacement. A finite straight step B + εηB generally leaves a curved target at order ε2; longitude/latitude changes instead stay exactly on that surface. Arrow lengths for momentum share the displayed scale; the normal component is not independently normalized. Target colors show straight-path endpoint cost, not potential energy.
