# PhysicsLibrary Book Licensing Audit

## Executive summary

The live scan probed PhysicsLibrary book object IDs **1–600** and detected **275 distinct book records** after removing repeated generic/error responses. Detected records span IDs **1–402**. The 2011 PlanetPhysics static snapshot is retained as an independent historical cross-check, but it contains rendered encyclopedia entries rather than the uploaded book objects.

This is a conservative triage audit: platform-wide GFDL boilerplate is not treated as a license for an uploaded third-party book. A permissive bucket requires book-local evidence. Ambiguous records remain in manual review.

Confidence totals: **high 15**, **medium 71**, **low 189**.

## Audit rules

- **CC:** explicit Creative Commons grant on the book page; exact CC variant still needs to be recorded before republication.
- **GFDL:** GNU/GFDL language must be tied to the book/document, not merely the site footer.
- **U.S. public domain:** the catalog explicitly claims public-domain status; edition/provenance remains a confirmation step, particularly for foreign works.
- **do-not-publish:** restrictive/private-use language is present and no affirmative reuse license is established.
- **questionable/manual review:** insufficient evidence either way; do not rehost until verified.
