# PhysicsLibrary Book Licensing Audit

## Scope and method

This report probed live PhysicsLibrary `books` object IDs **1–600** and retained responses that behaved as book-object pages rather than repeated generic/error pages. The 2011 static PlanetPhysics snapshot is used separately as a historical cross-check; it does not itself contain the uploaded book objects.

Classification is deliberately conservative. A site-wide footer or platform license is **not** treated as proof that an uploaded third-party book is reusable. Only book-local evidence supports CC/GFDL/public-domain assignment. Anything ambiguous is routed to manual review.

The buckets are exactly: **CC**, **GFDL**, **U.S. public domain**, **do-not-publish**, and **questionable/manual review**.
